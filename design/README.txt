TRADEPILOT — DESIGN FOUNDATION

Files:
- index.html: complete standalone website prototype (HTML, CSS, JavaScript).

How to open:
1. Download and extract the ZIP file.
2. Open index.html in Chrome, Edge, Safari, or Firefox.
3. No installation or internet connection is required for this prototype.

Notes:
- This is a front-end design prototype with sample/demo data.
- It is not connected to a broker, live market data, Supabase, or Excel.
- The trade planner is an illustrative position-size calculator using a $1,000
  reference account and 1.5% risk per trade.
